# Netflix Wrapped (Stylish Web Edition)

A bold, glassmorphism-inspired single-page "Netflix Wrapped" experience similar to Spotify Wrapped.

## Stack
- HTML5
- Modern CSS (gradients, glassmorphism, responsive grid)
- Vanilla JavaScript (dynamic rendering of cards/lists)

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.
